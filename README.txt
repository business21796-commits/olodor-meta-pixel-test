OLODOR TEST WEBSITE — META PIXEL TRAINING

Files:
- index.html       = Store / products / AddToCart
- checkout.html    = Checkout / InitiateCheckout
- thank-you.html   = Thank You page / Purchase

NEXT STEPS:
1. Upload these files to a public web host (for example GitHub Pages).
2. In Meta Events Manager, open your Dataset and choose Install Meta Pixel.
3. Copy the Meta Pixel base code.
4. Paste the SAME base code inside <head> on all three HTML pages.
5. Publish the website again.
6. Open the website and use Meta Events Manager > Test Events.
7. Test:
   PageView -> AddToCart -> InitiateCheckout -> Purchase

IMPORTANT:
- The website is for training only.
- The Purchase event is currently commented out until you install your real Meta Pixel ID.
- Do not use a fake Pixel ID.
